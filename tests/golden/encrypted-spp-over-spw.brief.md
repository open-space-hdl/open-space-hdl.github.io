# encrypted_spp_over_spw: build brief

Encrypted packets over SpaceWire: the OpenCrypto framer cuts every input packet (for example a compressed image) into chunks, the AES-GCM core encrypts every chunk with a generated IV and a 4-byte position in the AAD, and OpenSPP sends every encrypted chunk as one Space Packet through an N-Char adapter and an OpenWire port.

This brief was generated by the Open Space Composer from the system file `encrypted_spp_over_spw.composer.json` (catalog `22fe96cb3252`).
The file holds the system as edited (`instances`, `connections`, `externals`) and, in `resolved`, the netlist it resolves to.

- Asynchronous clock groups: `Clk_link`, `Clk_sys` (no timing paths between them; the crossings are Open Logic blocks).
- False path from `Rst`: Asynchronous reset input; the reset generators synchronise its release.
- False path from `spw0_Spw_DIn`, `spw0_Spw_SIn`: Inputs that spw0 synchronises itself.
- Output registers in the I/O blocks for `spw0_Spw_DOut`, `spw0_Spw_SOut`: Place the output flip-flops of data and strobe in the I/O blocks with matched routing.

## 6. Notes from the user guides

**Chunk framer** (`ocr_framer`, `frm0`): https://openspacehdl.org/opencrypto/docs/user_guide.html

- The slot Cfg_Slot is loaded for generated IVs and stays unchanged while the framer holds chunks.
- Every chunk consumes one invocation of the slot; save the counter regularly (GCM 9.1).
- A receiver decrypts every chunk on its own (IV bytes 0 to 11, AAD bytes 12 to 15, tag the last 16 bytes), orders the chunks by the invocation counter and finds the packet boundaries in the positions.

**AES-GCM core** (`ocr_core`, `ocr0`): https://openspacehdl.org/opencrypto/docs/user_guide.html

- Rst is synchronous and high-active; synchronise its release to Clk, for example with olo_base_reset_gen with SyncTmr_g = true.
- After the reset the key table erases every slot (NumKeys_g cycles, STATUS.BUSY = '1'); no key survives a reset.
- One context per message, in the order of the messages; the core pairs the n-th context with the n-th message.
- Load every key slot in use through the registers before sending contexts (programming sequence of the user guide).
- Without the release buffer, discard every decrypted message whose last beat carries the error flag or whose status is not OK.
- Save the invocation counter of every slot with generated IVs regularly ahead of the operational value (GCM 9.1).

**Space Packet node** (`spp_core`, `spp0`): https://openspacehdl.org/openspp/docs/user_guide.html

- Rst is synchronous and high-active; synchronise its release to Clk, for example with olo_base_reset_gen.
- After the reset the core initialises both APID tables (2048 clock cycles); packets are sent and delivered once the tables are ready.
- Serve every receive port, or place a buffer behind a port whose user can stall for long.
- TxBufferBytes_g holds the longest SDU of a port, RxBufferBytes_g the longest Space Packet.
- Hold the side band (TUser) of a send port constant during an SDU.
- The user supplies the packet secondary header at the start of the Octet String and keeps the secondary header flag of an APID static.

**N-Char adapter** (`spp_nchar`, `nchar0`): https://openspacehdl.org/openspp/docs/user_guide.html

- A received end of packet marker without data characters is discarded.

**SpaceWire port** (`owr_core`, `spw0`): https://openspacehdl.org/openwire/docs/user_guide.html

- LVDS output buffers for data and strobe and LVDS input buffers with fail-safe biasing belong to the top level; the core contains no I/O buffer.
- Enable the safe implementation of state machines in the synthesis tool.
- Set INT_HOLDOFF and INT_ACK_DELAY for the network before distributed interrupts are used.
- Serve the indication ports before the indication FIFO (16 entries) fills.
- Write registers as 32-bit words; a read that depends on a write waits for the write response.

## 8. Verification

A smoke testbench `encrypted_spp_over_spw_tb` (VHDL-2008, no extra libraries):

1. Instantiate `encrypted_spp_over_spw` and drive `Clk_sys` at 100 MHz, `Clk_link` at 200 MHz.
2. Hold `Rst` at '1' for 16 cycles of the slowest clock (100 MHz), then '0'.
3. Keep every external input idle: stream inputs with valid at '0', ready inputs of external outputs at '1', bus requests idle, pins at '0'.
4. Run for at least 100 us (the blocks initialise their tables after the reset) and stop the simulation: it must end without failed assertions, and the handshake outputs of the top level (valid, ready) and the line outputs must not be 'U' or 'X' after the reset. Data outputs may stay undefined while their valid is '0'.
5. Where an AXI4-Lite port is external, read its first register (the identification register of the block, see its user guide) and compare it with the documented value.

With GHDL: analyse the libraries of section 1, then `ghdl -i --std=08 encrypted_spp_over_spw.vhd encrypted_spp_over_spw_tb.vhd`, `ghdl -m --std=08 encrypted_spp_over_spw_tb` and `ghdl -r --std=08 encrypted_spp_over_spw_tb --stop-time=100us --assert-level=error`.
